Progressive Destruction Toolkit

Progressive, structural, recoverable destruction for gameplay.

Progressive Destruction Toolkit is a gameplay-oriented destruction system for Unity built for destruction that continues after the first break. The current validated package supports editor-authored fracture data, progressive damage routing, connectivity-driven structural secondary collapse, re-hittable fallen components, and Safe Recovery.

Progressive Damage

Repeated attacks can accumulate damage against stable authored Fragment identities instead of forcing an all-at-once shatter.

Structural Secondary Collapse

Support and connectivity determine which connected regions remain standing and which become coherent dynamic bodies.

Re-hittable Fallen Components

Fallen multi-Fragment components remain in the destruction lifecycle and can repartition as additional existing authored Fragments detach.

Safe Recovery

Restore the destruction baseline and run another destruction cycle without consumer-side manual Fragment reconstruction.

Pre-release status. Physical secondary-impact destruction and visual damage diagnostics are targeted for v1.0, but are not advertised here as shipping features until release validation is complete.
