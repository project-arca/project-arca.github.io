Progressive Destruction Toolkit

Progressive, structural, recoverable destruction for gameplay.

Progressive Destruction Toolkit is a gameplay-oriented destruction system for Unity built for destruction that continues after the first break. The frozen v1 runtime feature line includes editor-authored destruction data, progressive local damage, bounded ContactMap transmission, connectivity-driven partial collapse, re-hittable fallen components, optional physical secondary destruction, Safe Recovery, and visual damage diagnostics.

Progressive Damage

Repeated attacks can accumulate damage against stable authored Fragment identities instead of forcing an all-at-once shatter.

Structural Secondary Collapse

Support and connectivity determine which connected regions remain standing and which become coherent dynamic bodies.

Re-hittable Fallen Components

Fallen multi-Fragment components remain in the destruction lifecycle and can repartition as additional existing authored Fragments detach.

Physical Secondary Destruction

Configured released Toolkit bodies can create a new destruction attack when they later make a qualifying real physical collision.

Safe Recovery

Restore the destruction baseline and run another destruction cycle without consumer-side manual Fragment reconstruction.

Visual Damage Diagnostics

Inspect received, applied and accumulated damage plus transmission-hop context while tuning destruction behavior.

Pre-release status. The v1 runtime feature set is frozen, but the product is still in commercial hardening. Showcase completion, paid release-artifact validation, final supported-version/platform evidence, licensing/provenance review, and Asset Store submission are still pending.

Important limitations

Gameplay-oriented by design.

Structural collapse is connectivity/support based, not FEM or structural engineering analysis. v1 does not include a generic Ground Destruction domain or recursive runtime subdivision of one authored Fragment into newly generated finer Fragments.

Source-mesh authoring constraints apply. Final supported Unity versions, render-pipeline details, platforms, and measured performance guidance will be published from the validated release artifact.
