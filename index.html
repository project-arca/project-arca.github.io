Progressive Destruction Toolkit

Progressive, structural, recoverable destruction for gameplay.

Progressive Destruction Toolkit is a gameplay-oriented destruction system for Unity built for destruction that continues after the first break. The frozen v1 runtime feature line includes editor-authored destruction data, progressive local damage, bounded ContactMap transmission, connectivity-driven partial collapse, re-hittable fallen components, optional physical secondary destruction, Safe Recovery, and visual damage diagnostics.

Progressive Damage

Repeated attacks can accumulate damage against stable authored Fragment identities instead of forcing an all-at-once shatter.

Structural Secondary Collapse

Support and connectivity determine which connected regions remain standing and which become coherent dynamic bodies.

Re-hittable Fallen Components

Fallen multi-Fragment components remain in the destruction lifecycle and can repartition as additional existing authored Fragments detach.

Physical Secondary Destruction

Configured released Toolkit bodies can create a new destruction attack when they later make a qualifying real physical collision.

Safe Recovery

Restore the destruction baseline and run another destruction cycle without consumer-side manual Fragment reconstruction.

Visual Damage Diagnostics

Inspect received, applied and accumulated damage plus transmission-hop context while tuning destruction behavior.

Important limitations

Gameplay-oriented by design.

Structural collapse is connectivity/support based, not FEM or structural engineering analysis. v1 does not include a generic Ground Destruction domain or recursive runtime subdivision of one authored Fragment into newly generated finer Fragments.

Source-mesh authoring is currently limited to readable, closed, connected, consistently wound, two-manifold, convex meshes with positive uniform scale; the configured authored Fragment count is 2–128. Physical secondary destruction requires explicit setup. The Toolkit does not guarantee a universal frame rate.

Release-validated configuration: Unity 6000.4.7f1 on macOS Apple Silicon. The Core Toolkit and Minimal Consumer reference sample were validated with the Built-in Render Pipeline; the interactive Showcase Arena uses URP 17.4.0. Actual Mac Standalone tests used ARM64, Mono and Development builds.

Windows x64, Linux, mobile, Web, consoles, other Unity versions, Intel Mac and IL2CPP Player builds have not been release-validated. This is a verification/support-scope limit, not a claim that those configurations are incompatible.

Public quick-start overview

  1. Import the commercial .unitypackage into a fresh project with the verified Unity version.
  2. Open Tools > Progressive Destruction > Destruction Authoring and create the DestructionQuery layer if prompted.
  3. Open Samples / Minimal Consumer / MinimalConsumer for fixed-target physical hit and Safe Recovery integration.
  4. In a project configured for URP 17.4.0, open Samples / Showcase Arena / ShowcaseArena for guided interactive collapse, fallen re-hit, secondary contact and Recovery.

The Minimal Consumer panel does not provide a general fallen-component targeting button; this interaction is available through the public API and directly demonstrated in the URP Showcase. Full technical instructions are included locally with the package. See Important limitations above. Private development repositories are not customer documentation.
